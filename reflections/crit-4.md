# Crit 4 — An instrument

## 1. What was the breakthrough that moved the work forward?

Discovering that a critical component of this project was not just how a tool could produce drum and bass but how fast the interface felt. This was why removing the “click to start” screen was a big deal. Everything became the unlock. Beats were made by tapping a grid cell, bass pads were made by holding pads, and keys were used. After that, the project really started to feel like it was inspired by my friend who DJs and produces drum and bass. It really helps to use a tool as a quick sketchpad when trying to flesh out ideas.

## 2. What did this work change about who I want to be as a software developer?

This project also gave me a different outlook on testing creative software. Some tests could answer obvious things like null audio files and a beat generator that included common drum patterns. But you can’t test how the ride sounds or how a Reese bass feels or how the filter responds.

Talking through my project with my friend helped me come up with some conclusions. He liked the Reese detune and filter controls and complimented the bass, saying he thought of it as a layer of sine and square waves. Still, he noted that the ride needed improvement, that efficient drum samples would probably be a better substitute and that the low-pass filter could be stronger, so turning it fully off would leave just some bass. He also recommended dialling back the complexity of the Reese and making it a square wave with a pair of voices that are controlled by the detuning knob.

The main takeaway was that this crit was about sitting back and listening, playing, and seeing where this system doesn't fulfil what musicians need, as well as how it could be improved. The agent could help with the building and testing of the system, but the ultimate assessment was about how it feels using it as an instrument.
